# MAPA DE LINKS E SEO — GPS.dev AgroCore

Edite todos os links externos em:

`config/conteudo.js`

Campos disponíveis:

- `blog` — WordPress / site principal
- `linkedin` — perfil LinkedIn
- `youtube` — canal YouTube
- `medium` — perfil/publicações Medium
- `substack` — newsletter Substack
- `github` — GitHub
- `portfolio` — portfólio
- `aplicativo` — AgroCore Mobile

## Estratégia

A landing oficial deve funcionar como hub central da marca.

GPS.dev AgroCore
→ Blog WordPress
→ LinkedIn
→ YouTube
→ Medium
→ Substack
→ GitHub
→ Portfólio
→ AgroCore Mobile

Isso cria uma malha de links entre sua marca, conteúdo, autoridade e produto.

## Atenção

Use sempre os mesmos:
- nome profissional;
- descrição curta;
- URL principal;
- identidade visual;
- palavras-chave principais.

Não duplique textos idênticos em todas as plataformas; adapte cada publicação e aponte de volta para a página oficial.
